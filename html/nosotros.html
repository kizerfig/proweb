🤝 Sobre El Proyecto y El Equipo

Plataforma web oficial desarrollada en el ámbito académico para la Copa Mundial de la FIFA 2026™.

🎓 Contexto Académico

Esta aplicación ha sido desarrollada cumpliendo estrictamente con los estándares W3C, HTML5 Semántico, CSS3 Puro y JavaScript ES6+ Vanilla, como proyecto integral para la materia:

🏫 Universidad Católica Andrés Bello (UCAB Guayana)

Cátedra: Programación Orientada a la Web

⚡ Stack Técnico & Restricciones

  • ✅ HTML5 Semántico: Accesibilidad a11y y estructura clara.
  • ✅ CSS3 Puro: Variables en :root, modo oscuro y media queries nativas.
  • ✅ JavaScript ES6+ Vanilla: Programación modular con 0 dependencias externas.
  • ✅ Persistencia Local: Sistema de caché inteligente con LocalStorage (15 min TTL).
