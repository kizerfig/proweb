Cátedra: Programación Orientada a la Web

Tecnologías y Estrategia de Optimización

Este proyecto fue construido utilizando HTML5, CSS3 y JavaScript Vanilla. Para optimizar el rendimiento y la velocidad de carga de la información consumida desde nuestra API, implementamos una estrategia de Caché Local (LocalStorage) que almacena temporalmente las respuestas, reduciendo drásticamente las peticiones redundantes y mejorando la fluidez del sitio.

Diseño Responsivo

Nuestra plataforma cuenta con un Diseño Web Adaptativo (Responsive Design) implementado completamente desde cero utilizando CSS Grid y Flexbox. Mediante el uso de Media Queries, garantizamos que todos los componentes, desde la navegación hasta las tablas de clasificación, se adapten fluidamente a cualquier tamaño de pantalla, ofreciendo una experiencia óptima tanto en dispositivos móviles como en monitores de escritorio.
